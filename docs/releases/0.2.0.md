# Unilink 0.2.0 Windows candidate

Source commit: `64c910b2223b984b5f1ca9b07ce111c7d68e40e5`.

This candidate improves setup, playback recovery and session consistency for
trusted-LAN use. The original installed application and its configuration were
preserved during verification. No public release or installation replacement
was performed.

## Changes

- Setup names Unilink consistently, supplies the stable viewer address and
  distinguishes optional account and English speech setup.
- Source selection acknowledges immediately while optional preparation runs.
  Old responses and stale forms cannot overwrite a newer session.
- Paused and failed playback keeps its controls visible. Mobile controls and
  error explanations fit the viewport; fullscreen captions clear the controls.
  Unmuting from zero restores audible volume.
- Subtitle failures have an independent retry. Background availability updates
  the status label without restarting playback.
- Queue changes show pending feedback, preserve keyboard focus and support
  undoing the last removal in the current session.
- Local and account progress states distinguish success, unsupported content
  and failure.
- Optional English setup runs from the host configuration page, repairs partial
  installations and verifies pinned dependencies plus local model loading.
- Desktop lifecycle operations are serialized, expose actionable failure states
  and preserve ownership when cleanup fails. Windows release builds use the GUI
  subsystem.

## Verification

- JavaScript: 116 tests and syntax checks passed; the final manifest change also
  passed the complete 22-test HTTP suite.
- English alignment: 10 Python tests passed; its alignment code is unchanged.
- Installed speech runtime: readiness passed after 86.6 seconds on the loaded
  host. Verification has a two-minute bound; installation has a 20-minute bound.
- Windows setup cancellation: the production runner terminated a disposable
  child and grandchild. No actual dependency installation was started.
- Browser: synthetic playback, subtitle failure/retry, queue focus/undo, setup
  save, simulated installer recovery, zero-volume recovery, fullscreen, paused
  controls and narrow-screen failure layout verified on disposable instances.
- Independent review: eight lenses, five corrected findings, separate validation
  and a final metadata/probe addendum; no actionable findings remain.
- Native optimized build and both Windows installer formats succeeded. The
  executable reports version 0.2.0, PE subsystem 2 (GUI), and `NotSigned`.
- The packaged server passed the version, setup page, waiting page, player asset
  and disposable-port cleanup smoke checks.
- Native lifecycle: all eight library tests passed in the optimized release
  profile with the production `tauri/custom-protocol` feature. Rust formatting
  checks also passed.

## Release boundary

The candidate is unsigned. Native tray interactions under forced failure,
clean-machine install/upgrade/uninstall, Linux packaging/runtime and actual
assistive-technology use remain unverified. Public distribution requires a
chosen destination and those platform checks. A source-review verdict does not
establish that the application has been deployed.

To roll back an evaluation, close the candidate and retain the previous
installer and configuration. Do not expose the local server port publicly.
